# Hero illustrations

Original, editable SVG artwork created for ZAPD. No external images, fonts, scripts or animation.

- Home: tooth, child and smile gesture.
- About: a connected group of people.
- Parents: adult, child and heart.
- Membership: membership card and checkmark seal.
- Join: application checklist and pencil.
- Directory: profile cards and magnifying glass.
- Events: calendar and highlighted date.
- Blog: open journal with illustrated article.
- Contact: envelope and conversation bubble.

The shared `HeroArtwork` component selects the illustration by route. A CSS overlay darkens the artwork independently of the text. All SVGs are decorative and hidden from assistive technology; headings retain the page meaning.
